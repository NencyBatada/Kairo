# Campaign model usage

Operations owns invocation credentials, provider-call reservations and immutable usage reports. CampaignRooms reads campaign totals through `IUsageLedger` using its existing campaign-read access checks. Queued stages and Ask previews supply campaign and run IDs from persisted records; telemetry headers never authorize accounting.

Each call reserves capacity before contacting its provider. SQL transaction-owned application locks serialize reservations for each brand and campaign. Repeated reservation/report callbacks use the same invocation and request IDs; changed payloads conflict. Reservations remain consumed after provider errors, timeouts, missing reports or an interrupted caller. They are never automatically refunded. Invocation tokens are hashed, expire after 25 minutes and permit only operations appropriate to their agent endpoint. Closing an invocation rejects new reservations while permitting identical callbacks and final reports until expiry.

Defaults are 100 text calls, 50 requested images and 10 requested generated video clips per campaign. Set `Kairo__Operations__Limits__TextCalls`, `Kairo__Operations__Limits__Images` and `Kairo__Operations__Limits__VideoClips` on both API and worker, or configure `GenerationLimits` in `deploy/environments.psd1`. Zero disables that generation category. Every retry, repair and regeneration reserves again. SDK inference retries are disabled; bounded callback retries retain their request ID. Veo polling does not start another generation. Deterministic video composition does not consume a generated-clip slot; its model and speech calls are recorded separately.

`GET /api/brands/{brandId}/campaigns/{campaignId}/usage` returns reserved capacity, actual reported usage, remaining limits, the sum of known estimated USD costs and an explicit completeness flag/count. Unknown model pricing, missing token details and uncertain failures remain unknown. Usage fields that do not apply to a provider operation do not affect totals for other operations. `generation_limit_exceeded` stops automatic stage and Guardian repair retries.

## Rate version google-standard-usd/2026-10-18.1

Rates were verified against [Google Cloud generation pricing](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing) and [Text-to-Speech pricing](https://cloud.google.com/text-to-speech/pricing), with generation rates checked again on 2026-10-23. [Google's Gemini pricing page](https://ai.google.dev/gemini-api/docs/pricing#veo-3.1) also identifies video pricing units as seconds. `UsageRates` includes standard on-demand Gemini 3.5 Flash, Gemini 3.8 Flash, Gemini 2.5 Flash Image, Veo 3.1 and configured Standard, WaveNet, Neural2 and Chirp 3 HD speech families. Other models remain explicitly unpriced.

The rate schedule distinguishes global and regional Gemini endpoints, cached input, image-output tokens and reasoning output. Gemini 3.8 Flash's published introductory rates end on 2026-12-31; the published 2027 rates apply to later reservations. Every estimated ledger entry preserves its rate version and value. Calculations use the requested model's rate; the provider's resolved model version is retained when supplied. The estimates do not apply free allowances, negotiated discounts, promotional credits, taxes, currency conversion, infrastructure or storage charges, and are not a reconciled invoice. Incomplete usage is never silently treated as zero.

CI evaluations use the separate bounded evaluation ledger and artifacts. They have no campaign invocation and do not consume campaign generation capacity.
